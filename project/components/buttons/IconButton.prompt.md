Icon-only button with pill radius — for toolbars, card actions, nav. Always give it a `label`.

```jsx
<IconButton label="Search"><SearchIcon/></IconButton>
<IconButton variant="solid" label="Add"><PlusIcon/></IconButton>
<IconButton variant="outline" size="sm" label="More"><DotsIcon/></IconButton>
```

Variants: `ghost` (default), `solid` (cyan), `outline`. Sizes: `sm | md | lg`.
