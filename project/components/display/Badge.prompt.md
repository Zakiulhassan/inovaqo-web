Status / label pill in mono uppercase.

```jsx
<Badge>New</Badge>
<Badge variant="solid">AI</Badge>
<Badge variant="success" dot>Live</Badge>
<Badge variant="warning">Beta</Badge>
<Badge variant="outline">v2.4</Badge>
```

Variants: `soft` (default cyan tint), `solid`, `outline`, `success`, `warning`, `danger`, `neutral`. `dot` adds a leading status dot.
